<h3 id="overview"><picture><source media="(prefers-color-scheme: dark) and (max-width: 640px)" srcset="assets/readme/dark/hm-overview.svg"><source media="(prefers-color-scheme: dark)" srcset="assets/readme/dark/h-overview.svg"><source media="(max-width: 640px)" srcset="assets/readme/light/hm-overview.svg"><img src="assets/readme/light/h-overview.svg" alt="Overview: Privacy-first on-device AI assistant with Linux sandbox & Material 3 Expressive" width="100%"></picture></h3>

**Local AI** is a state-of-the-art, open-source AI assistant application for Android engineered around **Google's Material 3 Expressive** design system. 

It provides an entirely private, locally sandboxed environment that unites multi-provider LLM routing, local vector memory (RAG), embedded Linux PRoot workspaces, real-time hardware telemetry, and fluid 60Hz/120Hz spring physics. 

All conversations, API keys, documents, vector embeddings, and tool executions reside **100% securely on your device**. There is zero telemetry, zero analytics tracking, and no external middleman server.

<h3 id="hardware"><picture><source media="(prefers-color-scheme: dark) and (max-width: 640px)" srcset="assets/readme/dark/hm-hardware.svg"><source media="(prefers-color-scheme: dark)" srcset="assets/readme/dark/h-hardware.svg"><source media="(max-width: 640px)" srcset="assets/readme/light/hm-hardware.svg"><img src="assets/readme/light/h-hardware.svg" alt="Hardware & Performance: Real-time CPU/GPU monitor, power limit sliders & 120Hz display timing" width="100%"></picture></h3>

Local AI includes an embedded low-overhead hardware telemetry engine and custom power-budget controls located under **Settings ➔ Advanced Settings**:

* **Real-Time CPU & GPU Usage Monitor**: Compact, live-animated monitor card sampling `/proc/stat` and JVM runtime telemetry to provide instantaneous percentage utilization metrics without draining background battery.
* **Dual Power Limit Sliders (Default 70%)**:
  * **CPU Power Limit**: Default set to `70%`, adjustable from `10%` to `100%` with haptic feedback ticks on every 5% step.
  * **GPU Power Limit**: Default set to `70%`, adjustable from `10%` to `100%` to prevent thermal throttling during intensive local inference passes.
* **Display Smoothness & 120Hz Optimization**:
  * Full support for variable refresh rate displays (60Hz, 90Hz, 120Hz).
  * High-performance Compose list keying and memoized state derivations (`derivedStateOf`) to eliminate frame drops and scrolling stutters.

<h3 id="updates"><picture><source media="(prefers-color-scheme: dark) and (max-width: 640px)" srcset="assets/readme/dark/hm-updates.svg"><source media="(prefers-color-scheme: dark)" srcset="assets/readme/dark/h-updates.svg"><source media="(max-width: 640px)" srcset="assets/readme/light/hm-updates.svg"><img src="assets/readme/light/h-updates.svg" alt="In-App Updates: Instant GitHub release downloads with live speed & resume persistence" width="100%"></picture></h3>

The dedicated **App Updates** section (located directly under About in Settings) connects straight to GitHub Releases:

* **Semantic Version Comparison**: Verifies if the GitHub release tag is strictly newer than the currently installed build (`v1.2`). Lower or identical versions report "App is Up to Date".
* **Live Progress & Download Speed Counter**: Dynamic progress bar calculating transfer speeds in real time (**MB/s** and **KB/s** updated every 500ms) with total/downloaded byte tallies.
* **Persistence & Force-Close Recovery**: Downloaded APKs are cached safely in external files storage. If the user closes the app or swipes it away from Recents, the completed file is recognized instantly on reopen—enabling direct installation without re-downloading.
* **One-Tap Package Installer**: Direct integration with Android's secure `FileProvider` to launch package updates seamlessly.

#### 📱 Option A: Download Universal APK (Recommended)
1. Go to the [Releases](https://github.com/smartworldarafath/Local-AI/releases) page.
2. Download the latest `LocalAI_1.2_debug.apk`.
3. Open the downloaded APK on your Android device and confirm installation.

#### 💻 Option B: Build from Source

**Requirements**
* **JDK**: OpenJDK 17 or newer
* **Android SDK**: Compile SDK 36, Target SDK 36, Min SDK 28
* **Node.js**: v20.x or newer (for bundling embedded `web-ui/`)
* **NDK & CMake**: NDK 26+ and CMake 3.22+ (for building native PRoot workspace binaries)

```bash
# 1. Clone the repository
git clone https://github.com/smartworldarafath/Local-AI.git
cd Local-AI

# 2. Build the embedded Web UI
cd web-ui
npm install
npm run build
cd ..

# 3. Assemble the single universal APK
./gradlew :app:assembleDebug

# 4. Output location:
# app/build/outputs/apk/debug/LocalAI_1.2_debug.apk
```

<h3 id="faq"><picture><source media="(prefers-color-scheme: dark) and (max-width: 640px)" srcset="assets/readme/dark/hm-faq.svg"><source media="(prefers-color-scheme: dark)" srcset="assets/readme/dark/h-faq.svg"><source media="(max-width: 640px)" srcset="assets/readme/light/hm-faq.svg"><img src="assets/readme/light/h-faq.svg" alt="FAQ: Frequently asked questions regarding local models, privacy, and Linux tools" width="100%"></picture></h3>

**Are my chats and API credentials private?**  
Yes, 100%. Local AI has no centralized accounts or telemetry collectors. All API keys and tokens are encrypted via Android's hardware-backed `EncryptedSharedPreferences` through `SecretKeyManager`. SQLite databases remain strictly within your device's private app sandbox.

**How does the Linux PRoot sandbox function?**  
PRoot uses the Linux `ptrace` system call to emulate root file systems and system paths entirely in user-space. It allows executing shell scripts, Python, and terminal utilities inside an isolated Linux environment on Android without requiring device rooting.

**What does the Dual Power Limit Slider do?**  
It sets software execution limits for concurrent CPU worker threads and GPU offload limits (default 70%). This prevents your phone from overheating or throttling battery health during heavy inference sessions.

**Can I run local models offline?**  
Yes. You can connect Local AI to local Ollama endpoints or on-device LLM servers running on your phone or local WiFi network.
